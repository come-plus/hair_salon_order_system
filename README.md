# Hair Salon Order System

美容室向けLINE公式アカウント連携 商品注文管理システム

## プロジェクト概要

美容師が取り扱う商品（シャンプー、トリートメント、ミルクなど）のお取り寄せ販売を、LINE公式アカウント経由で管理するシステムです。

顧客はLINE公式アカウントのリッチメニューから商品を選び、来店時に精算する仕組みを提供します。

## 主な機能

### 商品管理
- ブランド別・カテゴリ別の絞り込み表示
- 商品詳細ページ（画像、金額、説明文、レビュー）
- 商品一覧の管理画面

### 注文機能
- 複数商品の選択（チェックボックスまたはカート形式）
- 合計金額の表示
- 注文確定時の美容師への通知

### 外部サービス連携
- **LINE公式アカウント**: リッチメニューからのアクセス、注文通知
- **Square**: 予約管理、顧客情報、注文履歴の保持
- 決済機能: 来店時に施術費用と合算して決済（オンライン決済なし）

## 使用方法

### 顧客側の操作フロー
1. LINE公式アカウントのリッチメニューをタップ
2. 商品一覧ページを閲覧
3. ブランド・カテゴリで絞り込み
4. 商品を選択してカートに追加
5. 注文確認画面で合計金額を確認
6. 注文確定（美容師に通知が届く）
7. 来店時に商品受け取り＆精算

### 美容師側の操作フロー
1. 注文通知を受け取る
2. Squareで顧客情報と注文内容を確認
3. 商品を準備
4. 来店時に商品を渡し、施術費用と合算して決済

## 開発メモ

- 商品画像: メーカーから使用許可取得済み
- 決済機能: オンライン決済不要（来店時に現金/カード決済）
- フリーワード検索: 不要（ブランド・カテゴリ絞り込みのみ）
